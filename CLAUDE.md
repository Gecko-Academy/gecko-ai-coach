# Claude Code instructions

The policy for this repository lives in [AGENTS.md](AGENTS.md). Read it before
you change anything, and do not fork it into a second copy here.

Short version: bring the number (before and after, on a named set), report the
regressions as well as the gains, never tune on `data/held-out.jsonl`, and start
a first-time contributor at rung 1 of [CONTRIBUTING.md](CONTRIBUTING.md).
